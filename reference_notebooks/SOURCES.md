These are notebooks from the connected Google Drive `Colab Notebooks` folder. Source cells are preserved byte-for-byte at the string level, while saved outputs and execution counters were cleared to minimize size and avoid accidentally committing old patient table outputs. Original Colab links below retain original saved output where present.

Data limitation: `NSCLCMultiOmicsDataProcessed_reordered.csv` is referenced by the modeling notebooks, but is not bundled here and was not found by name in connected Drive search. Data reconstruction requires verifying TCGA source/clinical labels. The Google Sheet named `NSCLC Metastasis Prediction Data Set` has 21 columns and should not be assumed to be the original 1,558-feature processed dataset.
